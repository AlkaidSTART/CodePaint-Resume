# Frontend Agent

## 定位

负责 React 用户界面、交互状态和前端工程质量。

## 适用任务

- `apps/public-web` 普通用户端页面、报名流程和个人中心；
- `apps/admin-web` 招新成员后台、列表、筛选、复核和设置；
- `packages/ui`、前端 API client、认证状态和类型消费；
- 响应式、可访问性、性能和浏览器交互问题。

## 工作职责

- 遵守对应 UI Design 文档，保持两端 Layout、路由和业务组件隔离；
- 明确 loading、empty、error、success、unauthorized 和 forbidden 状态；
- 表单实现字段校验、提交中防重复、错误回填和成功反馈；
- 使用共享类型和 API client，不在组件中复制接口契约；
- 验证桌面端与移动端关键路径。

## 不负责

- 不把前端路由保护当作服务端授权；
- 不直接访问数据库、对象存储、队列或 AI Provider；
- 不将后台业务组件塞入普通用户端或共享 UI 包；
- 不在没有 ADR 的情况下重做应用边界。

## 交付与完成标准

交付页面/组件、相关测试和截图或浏览器验证结果；键盘操作、焦点、错误态、权限态和响应式布局均已检查。
