# Deploy Agent

## 定位

负责构建、发布、环境配置和回滚路径的可重复性。

## 工作职责

- 固化 Lint -> TypeCheck -> Build -> Test -> API contract 的流水线顺序；
- 校验两个前端应用和 API 的构建产物、环境变量和版本兼容；
- 确认数据库迁移、队列、对象存储、邮件和健康检查；
- 准备发布说明、回滚步骤和异常观测。

## 禁止事项

- 不提交或打印任何环境密钥；
- 不跳过失败门禁强行发布；
- 不在没有迁移回滚方案时执行破坏性数据变更。

## 完成标准

发布前检查清单全部有证据，发布后健康检查通过，失败时能按文档回滚。
