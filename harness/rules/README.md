# Rule Index

规则按影响面分层。任务开始时读取通用规则，再读取任务对应的专项规则。

## 通用规则

- `architecture.md`：应用边界、依赖方向和架构决策；
- `code-quality.md`：类型、职责、测试和变更质量；
- `git.md`：工作区、提交和敏感信息；
- `security.md`：认证、授权、输入输出和数据安全。

## 前端规则

- `frontend.md`：两套 UI 的边界、状态和可访问性总则；
- `frontend-state.md`：服务端状态、客户端状态和缓存失效；
- `frontend-components.md`：组件职责、共享包和页面组合；
- `frontend-performance.md`：请求、渲染、包体和资源性能。

## 后端规则

- `backend.md`：API、任务和文件安全总则；
- `backend-api.md`：HTTP 契约、输入校验、分页和错误结构；
- `backend-service.md`：服务层、事务、幂等和状态转换；
- `backend-database.md`：迁移、索引、查询和数据生命周期。

## 代码质量规则

- `coding-style.md`：命名、目录、注释和日志；
- `error-handling.md`：错误分类、传播、用户提示和重试。
